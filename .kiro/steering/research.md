# Lab rules

- Size the work to the change. For a fix of under 20 lines of code:
  each spec document under 100 words, 1 task, at most 2 tests.
  Ask me before going over.
- Tests check known answers, not one output against another.
- Make the smallest change that fixes the problem.
- Never report a number you didn't compute.
- Run Python with `uv run`.
